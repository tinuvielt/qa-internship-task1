# Промпты, использованные в работе

ИИ использовался как помощник для проверки полноты покрытия и генерации шаблонного кода. Токены, пароли и секреты в промпты не передавались.

1. **План работы над заданием:**
   > Составь краткий план выполнения тестового задания QA: анализ UI-скриншотов с приоритетами P0-P3 и автоматизация REST API на Python (pytest, requests, pydantic, allure, ruff).

2. **Проверка скриншотов в Задании 1:**
   > Сравни форму редактирования объявления с карточкой товара и карточкой продавца. Выпиши расхождения по ценам, характеристикам, статусам и вёрстке и помоги распределить их по приоритетам P0-P3.

3. **Тест-кейсы и каркас тестов для API:**
   > По списку ручек (/api/1/register, /api/1/autorize, /api/1/item, /api/1/{sellerID}/item, /api/1/statistic/{id}, /api/2/statistic/{id}, /api/2/item/{id}) набросай матрицу проверок (позитив, негатив, граничные значения, проверка Bearer-токена и чужого sellerID) и структуру проекта на pytest с Pydantic и фикстурами для очистки данных.
